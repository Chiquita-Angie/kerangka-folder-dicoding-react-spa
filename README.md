# Struktur Folder Submission Dicoding React SPA

Folder ini adalah kerangka struktur proyek, bukan pengganti starter project Dicoding.

## Struktur

src/
- components/ : komponen yang digunakan ulang
- pages/      : komponen untuk setiap halaman
- styles/     : stylesheet
- utils/      : fungsi pengelolaan data
- App.jsx     : konfigurasi route aplikasi
- main.jsx    : entry point React (nama file dapat disesuaikan dengan starter project)

## Penting
1. Salin folder-folder dan file yang dibutuhkan ke dalam starter project Dicoding yang sudah kamu unduh.
2. Jangan mengganti `src/utils/local-data.js` bawaan jika file tersebut sudah tersedia.
3. Sesuaikan nama file entry point dengan proyek. Starter project bisa menggunakan `index.jsx`, `index.js`, atau `main.jsx`.
4. Pasang `react-router-dom` hanya jika belum ada di `package.json`.
